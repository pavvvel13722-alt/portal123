# Руководство пользователя портала обработки обращений

## 1. Начало работы
1. Откройте файл `index.html` двойным кликом или через проводник файлов без запуска сервера.
2. В шапке выберите тему (светлая/тёмная) — выбор сохраняется локально.
3. Нажмите "Загрузить CSV" и выберите выгрузку. Поддерживаются UTF-8-BOM и Windows-1251, разделитель определяется автоматически.
4. Убедитесь, что после загрузки счётчик строк соответствует ожиданиям. Если нет — загрузите файл повторно.

## 2. Вкладка «Дубли обращений»
1. Откройте вкладку «Дубли обращений» и нажмите "Найти дубли".
2. В настройках можно включить/отключить учёт времени, задать окно дат и порог похожести (ползунок) или ввести стоп-фразы.
3. В списке результатов видны кластеры по авторам: основное обращение (вверху) и потенциальные дубли под ним.
4. Для каждого обращения доступны кнопки "Открыть" и "Сравнить описания". При открытии копируется текст закрытия дубля.
5. Кнопка с крестиком рядом с кластером убирает его из ленты, если дубли неподходящие.
6. Общий счётчик показывает количество дублей, которые следует закрыть.

## 3. Вкладка «Поиск по обращениям»
1. Введите ключевые слова в строку поиска; поиск работает по полям Автор и Описание.
2. Выберите статусы и приоритеты в выпадающих списках (множественный выбор поддерживается).
3. Нажмите "Найти". Ниже появится таблица: ID, Описание (с подсветкой совпадений), Создано, Статус, Приоритет.
4. Наведите курсор на ячейку «Описание», чтобы увидеть полный текст во всплывающей подсказке.
5. Кнопка "Сбросить фильтры" очищает выбор и сбрасывает поиск.
6. Экспорт "Экспорт результатов (CSV)" сохраняет текущую таблицу в формате `ID;Автор;Описание;Создано;Статус;Приоритет` с BOM для Excel.

## 4. Вкладка «Поиск тегов»
1. Выберите один или несколько шаблонов (поле «Название» в CSV) и статусы, по умолчанию Решено/Выполнено.
2. Настройте параметры извлечения: минимальная частота, n-граммы 1–3, минимальная длина токена, топ-N.
3. Нажмите "Найти теги" — справа появится заголовок "Шаблон: <Название> (обращений: M)".
4. Чипы тегов показывают score и частоту; их можно удалять или добавлять вручную. Правки сохраняются в localStorage.
5. Таблица топ-фраз содержит фразу, частоту, df, tf-idf и итоговый score. Сортировка — по score.
6. Экспорт доступен в CSV (`Шаблон;Тег;Score;Частота`) и JSON (`{"Шаблон":["тег1","тег2"]}`); кнопка "Копировать теги" копирует текущий набор.

## 5. Общие функции
- Все данные и настройки сохраняются локально в браузере; портал работает офлайн.
- В каждой вкладке есть сворачиваемые подсказки и параметры; используйте их для краткой справки.
- Для ссылок на обращения используется формат `https://sfera.vtb.ru/sd/support?open=<ID>` с автоматическим кодированием ID.
- В случае некорректных данных загрузите файл заново или проверьте кодировку/разделитель.
