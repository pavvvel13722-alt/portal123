    Справка: дубли обращений

    Анализ ищет совпадения по автору и описанию. Окно времени ограничивает сравнение по дате создания.

    Алгоритм

    1. Тексты очищаются от приветствий, приводятся к нижнему регистру и нормализуются.
    2. Похожесть считается по триграммам и трёхсловным фразам.
    3. Порог зависит от длины описания или задаётся вручную.
    4. Группы формируются по автору, главным считается самое позднее обращение.

    Если группа не является дублем, нажмите "Скрыть группу", чтобы убрать её из списка.

    Справка: поиск по обращениям

    Поиск выполняется по автору и описанию. Ключевые слова из категорий дополняют запрос и повышают вес совпадений.

    • Используйте мультивыбор статусов и приоритетов, чтобы ограничить выдачу.
    • Нажмите "Экспорт CSV", чтобы сохранить текущую таблицу.
    • Категории можно импортировать и экспортировать в формате JSON.

    Справка: поиск тегов

    Выберите шаблон и статусы. Сервис посчитает повторяющиеся фразы и предложит теги с оценкой важности.

    1. Минимальная частота отсекает редкие фразы.
    2. Минимальная длина слова помогает убрать союзы и предлоги.
    3. Количество тегов определяет размер итогового списка.

    Результаты можно редактировать вручную и сохранять в localStorage.
